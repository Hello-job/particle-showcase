# 可读 TypeScript 粒子核心验收

日期：2026-09-06。旧编译基线为 `typescript-showcase-v1`（`85663be`），本次重构位于 `refactor/readable-particle-engine`。

## 实际变更

此前保留的是粒子渲染的依赖模块：包括生成、运动、配置、后处理和通用 SVG 解析，以及原打包器的加载包装；并非整站导航、登录或统计功能。当前核心改为 `src/particles/core/` 下的可读 TypeScript，移除数字模块工厂和适配加载器。SVG 解析复用固定版本 Three.js 自带的 SVGLoader。

React 组件、DOM 协调和底层核心都有类型检查。当前 `src/` 与 Skill starter 的 `src/` 不含 `.js` / `.jsx` 文件；着色器仍是 GPU 所需的 GLSL 源码。原编译实现留在 Git 基线中，当前项目和 Skill 不再携带它。

这是基于已知实现的可读重构，不是恢复原作者丢失的变量名、注释或 TypeScript 源文件。阅读入口和来源见 [core 指南](../../src/particles/core/README.md)。
